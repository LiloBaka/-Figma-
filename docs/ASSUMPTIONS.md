# Допущения этапа 0

## Подтверждено

- В `spec/assets.json` описано 10 именованных ассетов, по четыре варианта
  каждого; все 42 пути к SVG из этого манифеста существуют.
- Шесть путей к reference-шаблонам из `spec/templates.json` существуют.
- Всего проверено 48 путей из обоих манифестов (включая два
  `unclassifiedExtras`); отсутствующих файлов нет.
- Схема сцены допускает форматы `L`/`S`, роли `main`/`background` и требует
  координаты, поворот и порядок слоёв для каждого элемента.

## Рабочие допущения

- Архивные варианты `large`/`small` и `main`/`background` используются только
  как предварительная классификация, а не как подтверждённые Figma-метаданные.
- `unidentified-group` и соответствия `Group...` для small-вариантов остаются
  неподтверждёнными до визуальной проверки.
- Шаблоны — готовые reference-композиции, а не спецификация слотов или safe area.
- Наблюдаемые цвета SVG не являются семантической палитрой; исходные SVG менять
  нельзя.
- Для MVP этапа 5 канонический холст принят равным 1200×630 только потому, что
  все шесть reference-шаблонов имеют такой экспортный размер. Это не утверждает
  native dimensions форматов L/S.
- Повторный разбор шести SVG подтвердил одинаковый `viewBox="0 0 1200 630"`
  и размер экспорта для L и S. Различаются не размеры холста: в каждом L-шаблоне
  шесть `clipPath`-групп, в S — три, а их координаты и габариты отличаются.
  `src/templates.ts` хранит эти извлечённые прямоугольники и их общую рамку
  как reference slots/safe area; это не подтверждает семантическое соответствие
  групп конкретным asset ID или универсальные разрешённые позиции пользователя.
- Перед применением сцены плагин теперь читает `viewBox` каждого фактически
  переданного SVG и не создаёт узел, если его прямоугольник по координатам сцены
  выйдет за 1200×630. Поворот не включён в это ограничение: SVG-reference не
  задают правила поворота, поэтому точная повёрнутая safe area не утверждается.
- Safe area MVP: X=60…1140, Y=50…580. Три позиции для «Собранно», «Со
  смещением» и «Под заголовок» — консервативные детерминированные пресеты,
  выведенные без извлечения slot geometry из reference SVG; плагин не допускает
  координаты за этими границами.
- Минимальная палитра `observed-purple` ограничена прямыми заменами цветов,
  которые наблюдались в совпадающих path large main/background вариантов:
  `#181817 → #7864D7`; `#F9ECB0`, `#FFE3E1`, `#F9A3AA → #D7CDF5`.
  Это не подтверждённая семантическая token map: преобразование применяется
  только к точным hex в SVG-копии перед вставкой, не меняет исходники и не
  назначает роли остальным цветам.
