# Допущения этапа 0

## Подтверждено

- В `spec/assets.json` описано 10 именованных ассетов, по четыре варианта
  каждого; все 42 пути к SVG из этого манифеста существуют.
- Шесть путей к reference-шаблонам из `spec/templates.json` существуют.
- Всего проверено 48 путей из обоих манифестов (включая два
  `unclassifiedExtras`); отсутствующих файлов нет.
- Схема сцены допускает форматы `L`/`S`, роли `main`/`background` и требует
  координаты, поворот и порядок слоёв для каждого элемента.

## Рабочие допущения

- Архивные варианты `large`/`small` и `main`/`background` используются только
  как предварительная классификация, а не как подтверждённые Figma-метаданные.
- `unidentified-group` и соответствия `Group...` для small-вариантов остаются
  неподтверждёнными до визуальной проверки.
- Шаблоны — готовые reference-композиции, а не спецификация слотов или safe area.
- Наблюдаемые цвета SVG не являются семантической палитрой; исходные SVG менять
  нельзя.
