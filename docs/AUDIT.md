# Аудит соответствия требованиям

Дата аудита: 12.11.2026. Основание: `docs/source_handoff.md`, который
`CODEX_RULES.md` определяет как исходные требования, текущий код и манифесты.
Оригинальные PDF из `original_briefs/` не были независимо прочитаны: в среде
нет `pdfinfo` и `pdftotext`. Это не меняет выводов по текстовой расшифровке
требований, но ограничивает визуальную сверку с первоисточником.

| Требование | Статус | Доказательство | Критичность проблемы |
|---|---|---|---|
| Figma-плагин на TypeScript с отдельными main/UI entrypoints | готово | `manifest.json`, `src/code.ts`, `src/ui.html`, `scripts/build.mjs`; `npm.cmd run build` успешен | низкая |
| Предпочтенный React UI | отсутствует | UI — ванильный DOM в одном `src/ui.html`; React отсутствует в `package.json` | низкая: React назван рекомендуемой, а не обязательной технологией |

| Библиотека из 20 исходных объектов с метаданными | частично | `spec/assets.json` содержит 10 именованных asset ID × 4 варианта и 2 `unclassifiedExtras`; `docs/ASSUMPTIONS.md` прямо фиксирует неподтверждённость соответствий small/Group | высокая: состав библиотеки не соответствует буквально заявленным 20 объектам |

| 2–3 demo-композиции: main, смесь main/background, разные палитры/форматы | частично | Три demo-scenes есть: main, mixed и S/headline. Разных палитр нет, так как палитры не реализованы | высокая |
| Сборка и автоматические проверки | частично | Успешны `check:catalog`, `check:insert`, `check:scene`, `check:templates`, `check:metaphor`, `check:export`, `npm.cmd run build`. `python3 scripts/validate_assets.py` не выполнен: Python 3 отсутствует | средняя |
| Проверка реального поведения в Figma | отсутствует | `docs/PROGRESS.md` фиксирует, что Development plugin не запускался; нет подтверждения canvas edit, clientStorage, download или экспорта | высокая |

## Архитектурный вывод

Разделение UI, plugin main, модели сцены, шаблонов и offline picker достаточно
для MVP и сборка воспроизводима. Но граница между моделью сцены и Figma canvas
односторонняя: UI пересоздаёт контролируемый frame, а ручные изменения в Figma
не становятся состоянием сцены. Данные палитры, подтверждённые размеры L/S и
правила слотов отсутствуют в исходных материалах и не должны заменяться
выдуманными значениями.

## Границы аудита

Аудит статический: не запускал Development plugin, не изменял исходный код и
не устанавливал зависимости. Поэтому «готово» означает наличие реализации и,
где указано, успешную автоматическую проверку, а не подтверждённый результат
в Figma.
