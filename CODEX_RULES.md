# Правила для Codex (режим коротких итераций)

Проект: Figma Illustration Builder. Исходные требования: `docs/source_handoff.md`; манифесты: `spec/`. Исходные 40 SVG + 2 неопознанных вспомогательных файла не перезаписывать. Шаблонные SVG — референсы, а не готовая таблица слотов.

1. Выполняй ровно один файл `codex_stages/STAGE_XX.md` за запрос. Не переходи к следующему без нового сообщения пользователя.
2. Сначала читай `docs/PROGRESS.md`; читай только исходники, необходимые текущей задаче. Не сканируй 4,6 МБ референсов и PDF повторно.
3. Работай с минимальным диффом. Не переписывай созданную структуру и не меняй технологии без блокера.
4. Лимит работы: одна вертикальная функция + точечные тесты. Если становится слишком объёмно, закончи рабочий инкремент, запиши остаток в PROGRESS и остановись.
5. Запрещены новые геометрические path, растрирование, свободное изменение масштаба, выдуманные semantic palettes.
6. Не объявляй тест в Figma успешным без фактического запуска плагина в Figma.
7. Конец этапа: изменения, результаты команд, известные проблемы, следующий файл STAGE_XX. Краткий ответ (до 12 строк).
8. Никаких дополнительных фич, backend AI и расширенных рефакторингов до отдельного запроса.
