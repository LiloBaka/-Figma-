# Этап 7 — Экспорт, приемка и сдача

## Обязательный рабочий режим (экономия токенов)
- Работай ТОЛЬКО над задачами этого этапа. Не выполняй следующие этапы заранее.
- Вначале прочитай `CODEX_RULES.md`, `docs/PROGRESS.md` и указанные в этом этапе файлы. Не перечитывай все PDF и SVG без необходимости.
- Не устанавливай новые большие зависимости без необходимости и не исследуй интернет без конкретного блокера.
- Не переписывай уже рабочие части. Не меняй исходные `assets/**/*.svg`.
- Выполни только целевые проверки этого этапа; полный suite запускается на этапе 7.
- Если задание не укладывается в разумный объём, оставь рабочее состояние и запиши невыполненное в `docs/PROGRESS.md`. Не расширяй scope.
- После работы обнови `docs/PROGRESS.md`: реализовано, изменённые файлы, команды и их исход, блокеры, следующий шаг.
- Ответ короткий: результат, проверки, что осталось. На этом ОСТАНОВИСЬ.

## Объём этого этапа

**Открой:** `docs/PROGRESS.md`, `docs/ASSUMPTIONS.md`, `docs/source_handoff.md`; PDF открывай только по конкретной необходимости.

**Сделай:**
1. Добавь SVG-экспорт управляемого frame через Figma API (`exportAsync({format:'SVG'})` или совместимый путь), UI-действие скачивания.
2. Проверь экспорт на `<image>`, base64-raster и наличие векторных элементов. Не утверждай, что редактируемость проверена, если не запускал в Figma.
3. Реализуй 3 воспроизводимые demo-scenes: только main, main+background, другой формат/шаблон.
4. Запусти `python3 scripts/validate_assets.py`, build и целевые тесты; исправляй только ошибки блокирующие MVP.
5. Создай итоговый `README.md`: установка Figma plugin, сценарии, архитектура, демонстрации, ограничения, использованные AI-инструменты (укажи реально использованные).
6. Проверь `docs/PROGRESS.md` и явно раздели «проверено кодом/тестами» и «проверено в Figma».

**Готово, когда:** экспорт и README готовы, тесты прошли или ошибки документированы, 3 демо воспроизводимы.
**Не делай:** рефакторинг ради красоты, AI backend, расширение функциональности.
