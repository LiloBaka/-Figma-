# Этап 6 — Подбор по метафоре без API

## Обязательный рабочий режим (экономия токенов)
- Работай ТОЛЬКО над задачами этого этапа. Не выполняй следующие этапы заранее.
- Вначале прочитай `CODEX_RULES.md`, `docs/PROGRESS.md` и указанные в этом этапе файлы. Не перечитывай все PDF и SVG без необходимости.
- Не устанавливай новые большие зависимости без необходимости и не исследуй интернет без конкретного блокера.
- Не переписывай уже рабочие части. Не меняй исходные `assets/**/*.svg`.
- Выполни только целевые проверки этого этапа; полный suite запускается на этапе 7.
- Если задание не укладывается в разумный объём, оставь рабочее состояние и запиши невыполненное в `docs/PROGRESS.md`. Не расширяй scope.
- После работы обнови `docs/PROGRESS.md`: реализовано, изменённые файлы, команды и их исход, блокеры, следующий шаг.
- Ответ короткий: результат, проверки, что осталось. На этом ОСТАНОВИСЬ.

## Объём этого этапа

**Открой:** `spec/assets.json`, `docs/PROGRESS.md`.

**Сделай:**
1. Сделай словарь RU/EN ключевых слов и синонимов → существующие asset IDs/tags.
2. Напиши детерминированный picker: текст → 1–4 допустимых объектов, роли и ID разрешённого шаблона. При неизвестном запросе — понятный fallback.
3. Добавь поле «Метафора или заголовок», «Собрать» и короткое объяснение выбора.
4. Тестируй примеры: обучение, фокус, решение задач, совместная работа, неизвестный текст.

**Готово, когда:** сценарий по тексту работает полностью офлайн и не возвращает несуществующие IDs.
**Не делай:** сервер, ключи, SDK моделей, интернет-запросы.
