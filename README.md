# Illustration Builder — подготовленный пакет для Codex

**Назначение:** исходные векторы, техническое задание и структурированные манифесты для разработки Figma-плагина. Это **не готовый работающий плагин**.

## Что включено

- `assets/` — **10 сопоставленных типов объектов × 4 варианта = 40** исходных SVG, сохранённых побайтово без редактирования. `large/small × main/background` — интерпретация экспортированных коллекций, требует визуального подтверждения.
- `assets/_unclassified/` — ещё **2** маленьких `Vector.svg`, не включены в список основных объектов; всего SVG из четырёх ZIP — **42**.
- `spec/assets.json` — манифест с путями, исходными именами, размерами, хешами SHA-256 и тегами.
- `spec/templates.json` — 6 полноценных референс-композиций, а не автоматически готовые слоты размещения.
- `spec/colors_observed.json` — цвета, обнаруженные в исходниках; **не финальная утверждённая палитра и не semantic token map**.
- `spec/scene.schema.json` — JSON Schema для внутренней модели сцены.
- `references/templates/` — шесть оригинальных SVG-референсов, `1200 × 630` каждый.
- `references/sizing/` — два больших SVG-референса форматов L/S (не путать размер их холстов с размером экспортируемой сцены).
- `references/overview/` — исходный большой обзорный SVG.
- `docs/source_handoff.md` — оригинальный handoff пользователя.
- `original_briefs/` — три исходных PDF.
- `scripts/validate_assets.py` — автоматическая проверка исходных SVG и хешей.
- `CODEX_PROMPT.md` — **готовое задание для Codex**, с этапами и критериями приёмки.
- `docs/OPEN_QUESTIONS.md` — что не доказано имеющимися материалами.

## Быстрый старт

1. Распаковать ZIP в отдельную папку или репозиторий.
2. Из корня запустить `python3 scripts/validate_assets.py`.
3. Открыть папку в Codex и отправить текст из `CODEX_PROMPT.md`.
4. Реализовать рабочий Figma-плагин, не перерисовывая оригинальные SVG и не придумывая semantic palette mappings.

## Границы достоверности

- Названия `Group...` в маленьких вариантах сопоставлены по размерам и схожей геометрии; обязательно визуально проверить.
- Подтверждено **10 базовых типов** в четырёх пакетах, а не 20 независимых типов объектов. Исходное ТЗ говорит «20 иллюстраций»; возможно, оно имеет в виду другое множество компонентов.
- Цветные SVG содержат готовые цвета, но правила автоматической перекраски между всеми палитрами не заданы исчерпывающе.
- Свободный scale запрещён в handoff, а размеры референсов не дают исчерпывающих slot/safe-area правил.
- Без API-ключа AI-сценарий должен работать в deterministic/offline mode; секреты нельзя размещать в коде UI Figma-плагина.
